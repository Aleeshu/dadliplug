## Direction

Original and deliberately not AI-template-looking. Local credibility is the
product. Avoid generic map-app aesthetics.

## Screens (from the sketch, to be confirmed)

1. Map screen — pins, category filter bar, Featured rail on side or bottom
2. Business listing — photos, description, menu or services, hours, call,
   WhatsApp
3. Search and filter results
4. Featured / Spotlight browse
5. Offers and deals
6. Auth — sign up, sign in, profile, visit history
7. Review flow — request, write, submit
8. Business admin — claim listing, edit details, analytics, verify customers,
   reply to reviews
9. Team admin — create and edit listings, moderation queue, subscription
